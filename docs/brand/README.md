# VFS brand

The VFS mark is a folder holding a small graph: files today, connected knowledge tomorrow.
It uses the app's "Papel" palette (`docs/design/system.md`).

| File | Use |
|---|---|
| `vfs-logo.svg` / `vfs-logo-dark.svg` | Mark + wordmark, light and dark backgrounds (README header) |
| `vfs-mark.svg` / `vfs-mark-dark.svg` | Mark alone; `*-512.png` raster copies |
| `vfs-app-icon.svg` / `vfs-app-icon-1024.png` | App icon source; feed the PNG to `tauri icon` |
| `favicon.svg` / `favicon.ico` | Web favicon (16, 32, 48 px) |
| `vfs-social-preview.png` | GitHub social preview, 1280×640 |
| `geo/github-about.md` | GitHub About description, topics and social preview, set by hand in the repository settings |

Colours: terracotta `#a3471f`, paper `#faf8f3`, ink `#1f1e1b`; dark theme `#e39a73` on
`#1c1b19` with ink `#edeae3`. The wordmark is Atkinson Hyperlegible Bold, converted to
outlines so the SVGs render without the font. Keep clear space of a quarter of the mark's
height around it; do not recolour the graph or place the mark on busy images.
